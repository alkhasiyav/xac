# xac

Простой консольный калькулятор на Python (без зависимостей).

```bash
python3 calc.py              # интерактивный режим, выход — q
python3 calc.py "2 + 2 * 3"  # вычислить одно выражение
python3 -m unittest          # тесты
```

Поддерживаются `+ - * / // % **` (или `^`), скобки и десятичная запятая.
