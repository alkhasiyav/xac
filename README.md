# xac

Простой консольный калькулятор на Python (без зависимостей).

```bash
python3 calc.py              # интерактивный режим, выход — q
python3 calc.py "2 + 2 * 3"  # вычислить одно выражение
python3 -m unittest          # тесты
```

Поддерживаются `+ - * / // % **` (или `^`), скобки и десятичная запятая.

## Веб-версия

`index.html` — калькулятор в браузере: кнопки, ввод с клавиатуры и история вычислений.
Откройте файл в браузере, сервер не нужен.

## Сумерки и время намаза

`twilight/index.html` — интерактивная 3D‑модель для объяснения, почему на высоких широтах
летом сумерки не исчезают (и почему «полутора часов» после магриба хватает не везде),
как световое загрязнение скрывает первую зарю, и когда наступает время каждого намаза
с точки зрения положения Солнца. Откройте файл в браузере (нужен интернет для three.js и шрифтов).

Офлайн-версия для Windows и других ПК: `twilight/offline/twilight-offline.html` — один файл,
всё встроено (three.js, шрифты, карта), интернет не нужен; открывается двойным щелчком в Edge, Chrome или Firefox.
Пересобрать после изменений: `python3 twilight/build_offline.py <папка с npm-пакетами> twilight/offline/twilight-offline.html`
(инструкция в начале скрипта).
